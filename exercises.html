Exercise 2

CautionExercise 2

Identify the index and key variables of the aus_accommodation dataset.

Then use as_tsibble() to convert it into a tsibble.

library(fpp3)
read.csv(
  "https://workshop.nectric.com.au/wombat2026/data/aus_accommodation.csv"
)
NoteSolution

The index is Date and the key is State. Date is read as text, so parse it first.

accommodation <- read.csv(
  "https://workshop.nectric.com.au/wombat2026/data/aus_accommodation.csv"
)
accommodation |>
  as_tibble() |>
  mutate(Date = as.Date(Date)) |>
  as_tsibble(index = Date, key = State)

Exercise 6

CautionExercise 6

Decompose the cost of antidiabetic scripts, then plot its components and the seasonally adjusted series.

a10 <- PBS |>
  filter(ATC2 == "A10") |>
  summarise(Cost = sum(Cost) / 1e6)
a10_dcmp <- a10 |>
  model(STL(???)) |>
  components()

# Plot the components
a10_dcmp |> ???

# Plot the seasonally adjusted data
as_tsibble(a10_dcmp) |> autoplot(???)
TipHint

Are the patterns additive or multiplicative?

NoteSolution 
a10 <- PBS |>
  filter(ATC2 == "A10") |>
  summarise(Cost = sum(Cost) / 1e6)
a10_dcmp <- a10 |>
  model(STL(log(Cost))) |>
  components()

# Plot the components
a10_dcmp |> autoplot()

# Plot the seasonally adjusted data
as_tsibble(a10_dcmp) |>
  autoplot(exp(season_adjust)) +
  labs(y = "Cost ($ millions)")

log() makes the patterns additive, and exp() returns the seasonally adjusted series to dollars.

Is the seasonal pattern in the total subsidised prescriptions (Scripts) in Australia changing over time?

pbs_scripts <- PBS |>
  summarise(Scripts = sum(Scripts))

The number of scripts in December is dropping rapidly. They appear to be redistributed into Oct, Nov, and Jan.

Create a calendar plot for the first few months of pedestrians at Southern Cross Station.

NoteSolution 
pedestrian |>
  filter(Sensor == "Southern Cross Station") |>
  filter(yearmonth(Date_Time) <= yearmonth("2015 Apr")) |>
  ggplot(aes(x = Date_Time, y = Count)) +
  geom_time_line() +

Holidays (such as Easter and Anzac Day) have much lower counts.

Exercise 14

CautionExercise 14

Use an STL decomposition and gg_season() to clearly show the seasonal patterns in pedestrian traffic.

ped_dcmp <- pedestrian |>
  filter(Sensor == "Southern Cross Station") |>
  fill_gaps(Count = 0) |>
  model(STL(Count)) |>
  components()
ped_dcmp |>
  autoplot()
NoteSolution 
ped_dcmp |>
  gg_season(season_year, period = years(1L))
ped_dcmp |>
  gg_season(season_week, period = weeks(1L))

The weekly seasonal pattern interacts with the daily seasonal pattern, so the model doesn’t work here. STL is additive, so interactions between different seasonalities are not captured.
