Sub-daily granularity

mixtime() finds the granularity (e.g. 30 minutes), datetime() uses seconds.

Time arithmetic

Numbers shift time by its granularity:

yearmonth("2026 Nov") + 0:2
<mixtime[3]>
[1] 2026 Nov 2026 Dec 2027 Jan

Durations shift by calendar units:

date("2026-01-31") + months(1L)
<mixtime[1]>
[1] 2026-02-28

Differences are durations too:

date("2026-12-25") - date("2026-11-30")
<mixtime[1]>
[1] 25.0 days

Linear and cyclical time

Linear time moves forward, cyclical time repeats.

today <- date("2026-11-30")
yearmonth(today)
<mixtime[1]>
[1] 2026 Nov
month_of_year(today)
<mixtime[1]>
[1] Nov
day_of_week(today)
<mixtime[1]>
[1] Mon

Cyclical time is useful for finding specific seasons.

# Is it a weekday? (Saturday is day 6)
day_of_week(today) < day_of_week(6L)
[1] TRUE

Mixing granularities

Time of different granularities can be combined…

c(

Visualising time series

Time series visualisation helps us identify time series patterns.

These patterns include:

  • trends
  • seasonalities
  • cycles
  • covariates
  • events

They also help identify anomalies/outliers.

Time plots

The most common time series graphic is the “time plot”, created with autoplot().

pbs_scripts <- PBS |>
  summarise(Scripts = sum(Scripts))
pbs_scripts |>
  autoplot(Scripts)

Time plots of mixed granularities

stat_summary_time() aggregates in the plot.

aus_production |>
  ggplot(aes(x = Quarter, y = Gas)) +
  geom_time_line(colour = "grey60") +
  stat_summary_time(
    granule = years(1L), fun = mean,
    colour = "steelblue", linewidth = 1
  )

Incomplete years (2010) become NA.

Lag plots

A lag plot compares observations with those before them, coloured by season.

aus_production |>
  gg_lag(Gas, geom = "point", period = years(1L))

From lag plots to the ACF

Quarterly Australian beer production since 1992.

Shift a copy (blue) by one quarter, pairing each observation with the one before it.

Each pair is a point in the lag plot. The first observation has no pair.

The autocorrelation \(r_1\) is the linear relationship in this lag plot (blue line).

It is small and negative: the first bar.

At lag 2, quarters are paired with those half a year earlier.

Peaks meet troughs, so \(r_2\) is strongly negative.

At lag 3, quarters are paired with the next quarter of the previous year.

Like lag 1, these are neighbouring quarters.

At lag 4, quarters are paired with the same quarter a year earlier.

Peaks meet peaks, so \(r_4\) is large and positive.

Continue for lags 5, 6, …

The seasonal lags 8, 12 and 16 are strongly positive too.

The ACF plot: one bar for each lag plot.

Bars beyond the dashed lines are unlikely for uncorrelated data.

ACF plots

An ACF plot shows autocorrelations (lagged relationships). This helps to identify trends, seasons and cycles. Lags are durations (e.g. 12 months).

pbs_scripts |>
  ACF(Scripts) |> 
  autoplot()

Time series decomposition

Decomposition separates time series patterns into individual series.

Additive decomposition via STL

\[y_t = S_t + T_t + R_t\]

  • \(y_t=\) data at time \(t\)
  • \(T_t=\) trend-cycle component at time \(t\)
  • \(S_t=\) seasonal component at time \(t\)
  • \(R_t=\) remainder component at time \(t\)

Additive & multiplicative patterns

STL only works with additive patterns

\[y_t = S_t + T_t + R_t\]

Multiplicative!

STL for multiplicative patterns

While STL doesn’t work directly with multiplicative patterns, we have a transformational trick 🪄

\[\begin{align} y_t &= S_t \times T_t \times R_t\\ \log(y_t) &= \log\left(S_t \times T_t \times R_t\right)\log\\ &= \log(S_t) + \log(T_t) + \log(R_t) \end{align}\]

Other transformations

Multiplicative patterns aren’t always exactly multiplicative. Instead we often use power transformations via box_cox(y, lambda).

More info: https://otexts.com/fpp3/transformations.html

Time series features

STL decomposition based features include:

Seasonal strength (season_strength_year)

The signal to noise ratio of seasonality from 0-1.

\[\max\left(0, 1-\frac{\text{Var}(R_t)}{\text{Var}(S_t+R_t)}\right)\]

Trend strength (trend_strength)

The signal to noise ratio of trend from 0-1.

\[\max\left(0, 1-\frac{\text{Var}(R_t)}{\text{Var}(T_t+R_t)}\right)\]

Plotting features

These features can then be plotted to reveal the patterns and structure of many series.

tourism |>
  features(Trips, feat_stl) |>
  ggplot(aes(x = trend_strength, y = seasonal_strength_year, col = Purpose)) +
  geom_point() + facet_wrap(vars(State))

Time components (extra)

Split time into linear and cyclical parts.

time_components(
  date("2026-11-30"),
  year = lin(year), month = cyc(month, year),
  day = cyc(day, cal_isoweek$week)
)
# A tibble: 1 × 3
  year      month     day      
  <mixtime> <mixtime> <mixtime>
1 2026      Nov       Mon

Use the same parts to parse text.

time_parse(
  "30/11/2026", format = paste0(
    "{cyc(day, month)}/{cyc(month, year)}/",
    "{lin(year)}"
  )
)
